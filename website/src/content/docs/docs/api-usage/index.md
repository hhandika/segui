SEGUL core features are available as a library. Choose the guide for your programming language:

- [Python](/docs/api-usage/python/intro/): use `pysegul`, available on PyPI, without any Rust knowledge.
- [Rust](/docs/api-usage/rust-api/): add the `segul` crate to your Rust project.
- [R](/docs/api-usage/r-api/): call the SEGUL API from R using `rextendr`.
