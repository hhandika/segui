SEGUL comes in two interfaces: a **command-line interface (CLI)** and a **graphical user interface (GUI)**. Both run the same core, so they produce the same results.

<InterfaceOverview />

## Platform support

<PlatformMatrix />

See the [GUI](/docs/installation/install_gui/) and [CLI](/docs/installation/install_cli/#pre-compiled-binary) installation guides. For Linux, the CLI comes as a fully static binary for older distributions and a GLIBC-linked binary for newer ones. You can also [build the CLI from source](/docs/installation/install_cli/#source-code).

For long jobs, the interface makes little difference. Summarizing a whole-genome FASTQ sample took about the same time in both. Part of the memory gap is the GUI's own interface, as noted above:

<ReadSummary />

:::caution[Large inputs on mobile]
Picking files one by one makes phones and tablets copy each file into the app first, which is slow for large batches. For more than about 500 files, use **Add folder** or **Open archive** (one `.zip` or `.tar.gz` file) instead. See [file input](/docs/gui-usage/intro/#file-input).
:::
