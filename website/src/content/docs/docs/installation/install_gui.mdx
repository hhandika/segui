SEGUI is the native desktop and mobile GUI for SEGUL. It runs on Android, iOS, iPadOS, macOS, Windows, and Linux; there is no browser version. Install it from your platform's store, or download it from the [GitHub release page](https://github.com/hhandika/segui/releases).

<StoreBadges stores={["microsoft", "app", "play", "snap"]} />

## Install by platform

<Tabs syncKey="gui-platform">
<TabItem label="Windows">

**Requires** Windows 10 or newer, 64-bit.

<StoreBadges stores={["microsoft"]} />

**From GitHub:** download `segui-Windows-x86_64.zip` from the [release page](https://github.com/hhandika/segui/releases), extract it, and run `segui.exe`. Create a desktop or Start menu shortcut for easier access.

:::caution
Windows may ask before running an app downloaded from GitHub. Check that the file came from the official release page before selecting **More info** and **Run anyway**.
:::

</TabItem>
<TabItem label="macOS">

**Requires** macOS 12.0 Monterey or newer.

<StoreBadges stores={["app"]} />

Want to test new versions early? Join the beta on [Apple TestFlight](https://testflight.apple.com/join/LSJD5D0i).

</TabItem>
<TabItem label="Linux">

**Requires** Ubuntu 22.04 or another 64-bit distribution with GLIBC 2.34 or newer. Check yours with `ldd --version`.

<StoreBadges stores={["snap"]} />

**From GitHub:** download the package for your distribution from the [release page](https://github.com/hhandika/segui/releases).

<Tabs syncKey="linux-package">
<TabItem label="Debian and Ubuntu">

```bash
sudo dpkg -i segui-Linux-x86_64.deb
```

</TabItem>
<TabItem label="Fedora and RHEL">

```bash
sudo rpm -i segui-Linux-x86_64.rpm
```

</TabItem>
<TabItem label="Other">

Extract the archive anywhere, then run the `segui` executable inside it.

```bash
tar -xvzf segui-Linux-x86_64.tar.gz
```

</TabItem>
</Tabs>

</TabItem>

<TabItem label="Android">

**Requires** Android 8.0 Oreo (API 26) or newer. SEGUI runs on phones, tablets, and Chromebooks.

<StoreBadges stores={["play"]} />

**From GitHub:** install an APK from the [release page](https://github.com/hhandika/segui/releases).

<Steps>

1. Pick the APK for your device:
   - `segui-arm64-v8a-release.apk` for 64-bit ARM, which most modern devices use.
   - `segui-armeabi-v7a-release.apk` for older 32-bit ARM devices.
   - `segui-x86_64-release.apk` for 64-bit x86, used in some Chromebooks.
2. Allow your browser to install unknown apps. The setting is usually under **Settings › Apps › Special app access › Install unknown apps**.
3. Open the downloaded APK to install it.

</Steps>

</TabItem>
</Tabs>

:::note[Apple compatibility]
The Apple minimum versions above apply to the next SEGUI release containing the native-platform upgrade. Versions currently in the app stores may have different requirements; check the listing for the version you install.
:::

To build SEGUI from source, follow the [advanced guide](/docs/advance-guides/build-gui/).
