The GUI and CLI are self-contained, so you can install both on the same system without conflicts. Not sure which you need? See [CLI vs GUI](/docs/cli_gui/).

<Tabs syncKey="interface">
<TabItem label="GUI">

**SEGUI**, the SEGUL app, runs on Linux, macOS, Windows, Android, iOS, and iPadOS. It does not run in a web browser.

<TabItem label="CLI">

The quickest route on Linux and macOS:

```bash
curl -fsSL https://segul.app/install.sh | sh
```

Or with conda on Linux and macOS:

```bash
conda install bioconda::segul
```

<LinkCard title="CLI installation" description="Installer script, binaries for Windows and HPC, conda, Cargo, and source builds" href="/docs/installation/install_cli/" />

</TabItem>
<TabItem label="API">

```bash
pip install pysegul   # Python
cargo add segul       # Rust
```
