Update SEGUL to get new features and bug fixes.

## SEGUL GUI

App stores usually update SEGUI automatically. To check by hand, open your system's app store or app management settings. If you installed SEGUI from GitHub, download the new release and replace the old copy.

## SEGUL CLI

Update the CLI the same way you installed it. If you are not sure how, find where `segul` lives:

<Tabs syncKey="shell">
<TabItem label="macOS and Linux">

```bash
which segul
```

</TabItem>
<TabItem label="Windows">

```powershell
Get-Command segul
```

PowerShell 7 or newer also supports `which segul`.

</TabItem>
</Tabs>

Then follow the tab that matches the path:

<Tabs syncKey="cli-method">
<TabItem label="Installer script">

Path contains `~/.local/bin`, the installer's default folder. Run the installer again to get the latest release. Add `--dir` if you used a custom folder.

```bash
curl -fsSL https://segul.app/install.sh | sh
```

</TabItem>
<TabItem label="Cargo">

Path contains `.cargo/bin`. Reinstall with Cargo:

```bash
cargo install segul
```

</TabItem>
<TabItem label="Conda">

Path contains `miniforge` or `conda`:

```bash
conda update segul
```

Or with mamba:

```bash
mamba update segul
```

</TabItem>
<TabItem label="Binary">

Path is a folder such as `/usr/local/bin`, `~/bin`, or `C:\Tools`. Download the latest [pre-compiled binary](/docs/installation/install_cli/#pre-compiled-binary) and replace the old `segul` file with the new one.

</TabItem>
</Tabs>
