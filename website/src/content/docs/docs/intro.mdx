**Thank you for using SEGUL!** 🙏🏻

**SEGUL (SEquence and Genomic UtiLities)** is a fast, memory-efficient tool for phylogenomic
datasets, from a few Sanger loci to thousands of loci across hundreds of samples. It runs on
phones, tablets, desktops, and computing clusters. For an independent review, see the
[Chan 2024 perspective](https://onlinelibrary.wiley.com/doi/full/10.1111/1755-0998.13993).

<Aside>
The SEGUL CLI is on [Bioconda](https://anaconda.org/bioconda/segul) for Linux and macOS on
[ARM](https://en.wikipedia.org/wiki/ARM_architecture_family) or
[x86_64](https://en.wikipedia.org/wiki/X86-64) CPUs:

```bash
conda install bioconda::segul
# or
mamba install segul
```

See [installing with conda](/docs/installation/install_cli/#conda).
</Aside>
