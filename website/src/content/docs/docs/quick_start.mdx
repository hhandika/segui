SEGUL comes as a desktop and mobile app (GUI), a terminal command (CLI), and libraries for Python, Rust, and R (API). This page gets you from install to a first run.

## 1. Choose an interface

<ChooseInterface />

See [CLI vs GUI](/docs/cli_gui/) for platforms, feature differences, and benchmarks.

## 2. Install

<Tabs syncKey="interface">
<TabItem label="GUI">

Install SEGUI, the SEGUL app, from your platform's store. See the [GUI installation guide](/docs/installation/install_gui/) for requirements and other options.

<StoreBadges stores={["microsoft", "app", "play", "snap"]} />

</TabItem>
<TabItem label="CLI">

On Linux and macOS, the installer script picks the right build and needs no root access:

```bash
curl -fsSL https://segul.app/install.sh | sh
```

On Windows, or to install by hand, download the binary for your system, unpack it, and put `segul` on your `PATH`. The [CLI installation guide](/docs/installation/install_cli/) walks through each method.

<CliDownloads />

On Linux or macOS with [Bioconda](https://bioconda.github.io/) set up, you can use conda instead. It may not work on older Linux systems found on some HPC clusters. See the [Bioconda guide](/docs/installation/install_cli/#conda).

```bash
conda install bioconda::segul
```

</TabItem>
<TabItem label="Python">

PySEGUL is the Python binding to the SEGUL library. It needs no Rust knowledge.

```bash
pip install pysegul
```

</TabItem>
<TabItem label="Rust">

Add the SEGUL crate from [crates.io](https://crates.io/crates/segul) to your project. The same crate also works from [R](/docs/api-usage/r-api/), which needs some Rust knowledge.

```bash
cargo add segul
```

</TabItem>
</Tabs>

## 3. Run your first task

Try SEGUL with a small example dataset, then move on to your own data.

  <LinkCard title="Relaxed PHYLIP alignments" description="data-phylip.zip, sequential and interleaved" href="https://github.com/hhandika/segul/raw/main/examples/data-phylip.zip" />
  <LinkCard title="Concatenated NEXUS" description="data-concat-nex.zip, for splitting" href="https://github.com/hhandika/segul/raw/main/examples/data-concat-nex.zip" />
</CardGrid>

Genomic files are too large to bundle. Download reads or contigs from public repositories such as [NCBI SRA](https://www.ncbi.nlm.nih.gov/sra).

<Tabs syncKey="interface">
<TabItem label="GUI">

<GuiSteps />

<Steps>

1. Open the app and choose a task group in the navigation bar, such as **Alignments**. Then pick a tool, such as **Concatenate alignments**. On narrow windows, tap the tool name at the top to switch tools.
2. Select **Add file**, or **Add directory** on desktop, to add the input.
3. Choose an output folder and fill in any parameters the task needs. On mobile, output goes to the app's own folder.
4. Select **Run**. Open the output files in the built-in viewer, or export them as a ZIP or gzip archive.

</Steps>

:::caution
Phones and tablets copy each input file into the app first, so very large batches may not fit. See the [guideline for mobile users](/docs/gui-usage/intro/#specific-guideline-for-mobile-users).
:::

</TabItem>
<TabItem label="CLI">

<CommandAnatomy />

SEGUL detects the input format from the file extension. For other extensions, set it with `--input-format`. Common commands:

```bash
segul align concat -d alignments/   # Concatenate alignments
segul align convert -d alignments/  # Convert alignment formats
segul align summary -d alignments/  # Alignment summary statistics
segul sequence remove -d alignments/ --id="seq_1;seq_2" # Remove sequences
segul read summary -d reads/        # Read summary statistics
segul <command> <subcommand> --help # Options for any task
```

See the [command options](/docs/cli-usage/command_options/) for every flag.

:::note
SEGUL 0.19.0 introduced the `command subcommand` layout. Older versions use a single command and need an input format with a folder, such as `segul concat -d alignments/ -f nexus`.
:::

</TabItem>
<TabItem label="Python">

Concatenate a folder of NEXUS alignments into FASTA with a RAxML partition file:

```python
import pysegul

concat = pysegul.AlignmentConcatenation(
    "nexus",          # input format
    "dna",            # data type
    "output",         # output folder
    "fasta",          # output format
    "raxml",          # partition format
    "concatenated",   # output file prefix
)
concat.from_dir("alignments")
```

Most classes follow this pattern. Tasks with extra parameters, such as filtering or extraction, set the input first and then call a method. See the [PySEGUL guide](/docs/api-usage/python/intro/).

</TabItem>
